# Тип двигателя и документы

Обновление 2026-11-12. Фильтр работает в витрине главной и справочнике моделей. Неизвестные типы не считаются бензиновыми. Записи могут соответствовать нескольким вариантам. Объём не используется для определения топлива.

Источники дополнений: текущие явные описания витрины index.html (Aqua, Prius, Fit, Vezel, Carnival, Song Plus). Mazda CX-5 Japan: KF бензин/дизель https://www.mazda.co.jp/cars/passenger/cx-5_kf/ ; KM гибрид https://www.mazda.co.jp/cars/passenger/cx-5/ . Типы относятся к семейству, не каждому году.

Для реального лота поля: fuel_type (явный текст), document_status: not_checked/checking/missing/awaiting/epts_pending/epts_issued/pts_available. Положительные статусы требуют document_source и documents_checked_at YYYY-MM-DD. Заполнять только по проверенным документам. Нет данных — «Документы не проверены». Наличие ПТС не означает завершения всех проверок. Для справочных моделей документы проверяются у будущего выбранного автомобиля.

API публичных поисков не фильтрует реальные лоты и не поддерживает фильтр топлива; новая форма фильтра не подключена к этому API.
