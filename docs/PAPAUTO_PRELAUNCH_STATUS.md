# PAPAUTO — статус запуска сайта

**Текущий этап: сборка и проверка полного каталога и заявок.**

- Пользователь отложил перенос на REG.RU: сохранить действующие Render и Cloudflare/DNS без изменений.
- Не запускать SEO-продвижение, массовые переобходы, IndexNow и новые поисковые кампании до готовности всего сайта. Не меняем уже доступные URL и robots.txt только ради этого решения.
- Публиковать только аукционные фотографии конкретного лота, полноценный оригинальный аукционный лист, точное описание и проверенные параметры. Ни одной уличной/складской/стоковой картинки.
- База: 37 полных японских лотов; 146 исследовательских кандидатов, **0** готовых новых карточек с проверенными листами и коммерческими правами.
- Следующая цель: расширить список реально проверенных лотов, в первую очередь Япония, Корея, Китай; источник каждой фотографии и документа должен совпадать по лоту/аукциону/дате.
- До публичного старта проверить на iOS/Android/ПК: фильтры, все изображения и листы, карточки и заявки, ввод номера, Telegram-уведомления, стоимость доставки и доступность из РФ без VPN.
- Автоматические push-триггеры GitHub IndexNow приостановлены, но ручной `workflow_dispatch` сохранён для будущего запуска после согласования.
