# PapAuto — проверка свободных GitHub-источников аукционных фото и листов

**Проверено:** 14 ноября 2026. **Никому не писали.** **Новых лотов на сайт не добавляли.**

## Критерий

Нужны *фотографии конкретного автомобиля с аукциона (не улица, не стоянка, не дилер)*, подлинный полный аукционный лист **того же лота** с подтверждёнными номером, датой, пробегом, оценкой и правом коммерческого **самостоятельного размещения** обоих медиафайлов. Лицензия на код репозитория не равнозначна лицензии на фотографии.

## Проверка собственной базы PapAuto

- В основной ветке находится **37** записей ранее размещённых лотов и **92** JPG/WebP-файла в каталогах `assets/auction/home` и `assets/premium-auctions`.
- Список этих 37 записей ссылается на **123** уникальных путей изображений; **37** из них **не существуют в текущем дереве GitHub main** (например, `assets/auction/home/toyota-corolla-sport-2023-20038-photo-2.jpg`). Это технический аудит репозитория, не самостоятельное подтверждение 404 на текущем Render.
- Оставшиеся **6** неопубликованных файлов — ранее отозванные демонстрационные Audi Q2/Q3 2021. Строго не переиспользовать: в них были неподходящие уличные или дилерские фотографии и схемы.
- В подключённом GitHub нашёл только репозиторий PapAuto по тематике PapAuto/аукционов; дополнительного собственного аукционного медиаархива не обнаружено.
- Новых отдельных пригодных фото и полных листов, разрешённых для коммерческого импорта, на этом этапе: **0**.

## Что действительно бесплатно и почему пока не подходит

- [CarAPI](https://github.com/trustcarinfo/carapi) может отдавать отдельные лицензированные Wikimedia-фото моделей. Это **не аукционные лоты** и не привязано к конкретному аукционному листу. Не использовать для клиентской аукционной галереи.
- [SalvageAlert](https://github.com/SalvageAlert/SalvageAlert-auctions-dataset/blob/main/LICENSE) — опубликованные данные CC BY-NC 4.0; коммерческое использование не разрешено этой лицензией.
- [Car Data Pipeline Demo](https://github.com/albertovichrobert6-ai/car-data-pipeline-demo) — содержит **183 японские фотографии CarSensor** и лицензию MIT на код; отсутствуют полные листы тех же аукционных лотов и отдельное доказательство прав на фотографии.

## Дальнейшая техническая работа без контактов

1. Искать на GitHub фото **конкретных японских аукционных лотов** и полные листы с индивидуальным доказательством лицензии (правообладатель и коммерческий self-host).
2. Отдельно просмотреть источники `research/PAPAUTO_NEW_10_AUCTION_CANDIDATES_2026-11-14.json` и `research/PAPAUTO_EXTRA_AUCTION_SOURCES_2026-11-14.json`, но не выдавать их за бесплатные GitHub-медиа: это архивные страницы третьих сторон, права не подтверждены.
3. После подтверждения прав использовать существующий `scripts/import_auction_photos.py --dry-run`, затем проверку CI и мобильной галереи. Не публиковать на Render ничего, что не прошло эти проверки.
4. Отдельно устранить ссылки на отсутствующие изображения в старой базе после проверки реального HTTP-поведения Render.
