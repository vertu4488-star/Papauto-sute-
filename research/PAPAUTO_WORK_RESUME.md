# PapAuto — рабочая контрольная точка и инструкция восстановления
Дата обновления: 2026-11-08.

## Источники истины
- Публичный сайт: https://papauto.ru/
- Каталог: https://papauto.ru/catalog.html
- Архив примеров расчётов: https://papauto.ru/auction-archive.html

- Актуальное фактическое состояние публикации проверять через Render deploy + публичную страницу; простой GitHub commit не равен опубликованной версии.

## Принятые решения пользователя
1. PapAuto занимается автомобилями под заказ из Японии, Южной Кореи и Китая, приоритет рынка — Новосибирск и РФ.
2. Только настоящие, живые фотографии автомобилей; НЕ использовать сгенерированные картинки, коллажи с микроскопическим разрешением или фотографии другой модели под видом конкретного автомобиля.
3. Снимки из открытых поисковиков не становятся автоматически свободными. Использовать изображения с проверенными правами на коммерческое использование; оригиналы и сведения об источнике учитывать во внутреннем реестре. Предпочтение CC0, реальная фотосъёмка.
4. НИКАКИХ внешних ссылок на конкурентов/продавцов/Дром/JTECO в публичных карточках: нельзя уводить покупателя с PapAuto.
5. Нельзя выдавать обобщённый справочник или фотографию модели за настоящие индивидуальные архивные аукционные лоты. Даты торгов, цена и пробег должны быть достоверными и относиться к одному лоту.
6. Отдельный раздел архива завершённых торгов строить на подтверждённых результатах; никакой фальшивой статистики.
7. По цене «под ключ» важны C&F, валюта JPY/KRW/CNY, RUB/USD/EUR, пошлины, утильсбор, СБКТС, доставка Владивосток → Новосибирск; показывать допущения и дату расчёта.
8. Интерфейс компактный, адаптивный, светлый и строгий, без оранжевого; вкладки и фильтры вместо длинной ленты.
9. Для писем аукционам и другим внешним компаниям нужно отдельное разрешение пользователя; никаких несанкционированных обращений.
10. По возможности работать самостоятельно через подключённые GitHub / Render, проверять деплой и публичный сайт. При запросе кода на замену пользователю отдавать полный файл, не фрагмент.
11. Не расходовать платные браузерные ресурсы без необходимости, предпочтительнее прямые GitHub / Render.
12. Чат может исчезать из приложения iOS. Эта запись служит устойчивой точкой восстановления проекта независимо от ChatGPT UI; её можно найти в GitHub. ChatGPT не может автоматически бесконечно продолжать обычную сессию в фоне.
