# PAPAUTO site v7

Статический сайт для проекта PAPAUTO — подбор автомобилей из Японии, Южной Кореи и Китая с ориентиром на Новосибирск.

## Что есть
- Адаптивная главная страница и отдельные SEO-страницы направлений.
- Калькулятор суммирует только введённые пользователем значения и показывает незаполненные статьи.
- Форма подбора формирует текст заявки для копирования.
- Чек-лист перед оплатой и FAQ.
- robots.txt, sitemap.xml, canonical, Open Graph и JSON-LD.
- Подготовлены интеграции Telegram-бота, Telegram-канала, ВКонтакте, Instagram и YouTube через site-config.js.
- Реальные URL соцсетей будут отображаться в футере и попадать в JSON-LD sameAs.
- Не публикуются вымышленные лоты и фиктивные цены.

## Пока не подключено
- Формы не отправляют заявки владельцу; серверного API и базы данных нет.
- ИИ-помощник не подключён к языковой модели.
- Telegram-бот и социальные сети пока не связаны: добавьте официальные URL в site-config.js.
- Нет источника реальных автомобилей, аукционных лотов или обновляемых курсов/таможенных ставок.
- Политика конфиденциальности — шаблон, перед запуском её нужно заполнить и проверить.

## Render Static Site
- Build Command: `echo "Static site — no build required"`
- Publish Directory: `.`
- Подключить репозиторий и дождаться завершения deploy.
- После публикации добавить papauto.ru и www.papauto.ru в Custom Domains и настроить DNS у регистратора.

## SEO после публикации
1. Проверить canonical и абсолютные URL.
2. Подключить Яндекс Вебмастер и Google Search Console.
3. Отправить https://papauto.ru/sitemap.xml.
4. Подключать аналитику с учётом требований к уведомлению и согласию.
5. Проверить мобильную версию и структурированные данные.

## Telegram и соцсети
В site-config.js заполнить реальные HTTPS-ссылки: telegramBotUrl, telegramChannelUrl, vkUrl, instagramUrl, youtubeUrl. Не вставлять токен Telegram-бота в публичный JavaScript. Для API и секретов потребуется серверная часть с защищёнными переменными окружения Render.
