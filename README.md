# PAPAUTO — бесплатный этап

PAPAUTO — сайт подбора автомобилей из Японии, Южной Кореи и Китая с ориентиром на Новосибирск и доставку по России.

## Политика расходов
- В текущем режиме нет платных подписок, платных API-запросов, кредитов или автоматических покупок отчётов.
- Gemini, TKS.RU, XAPI Korea, TTPAI и платные отчёты JP Sheet отключены в пользовательских сценариях.
- Даже если старые ключи остались в переменных Render, endpoint TKS.RU отвечает 503 до обращения к поставщику.
- Не подключать тарифы, платные API, пополнение кредитов или автопродление без отдельного согласования.
- Render Free и бесплатные публичные источники имеют ограничения доступности и квот. Платные тарифы не включаются.

## Что реализовано
- Адаптивный сайт, страницы стран, регионов и отдельных моделей.
- Каталог с фильтрами. Если прямой бесплатный поток объявлений отсутствует, показывается источник/ссылка, а не выдуманный лот.
- Бесплатный локальный разбор естественного запроса и браузерный голосовой ввод (если браузер поддерживает SpeechRecognition).
- Избранное, сравнение до трёх автомобилей и до десяти сохранённых поисков в localStorage.
- Ручная смета с явными неизвестными расходами.
- Курсы валют Банка России и открытая агрегированная статистика USS, если публичный источник доступен.
- Карта маршрута с пометкой о схематическом морском участке.
- Источники поиска по Японии, Корее и Китаю с маркировкой типа данных.
- Заявки отправляются через настроенного Telegram-бота без обязательной платной базы данных; при сбое есть Telegram share fallback.
- Локальная история подготовленных заявок в браузере; не синхронизируется между устройствами.

## Честные ограничения
- Япония: нет лицензированной встроенной ленты текущих лотов и полного архива завершённых торгов. Есть открытые ссылки на внешние архивы.
- Корея: нет подтверждённого бесплатного API актуальных объявлений; Encar открывается как внешний источник. Публичная месячная статистика — агрегат, не список лотов.
- Китай: открытые каталоги открываются вручную. Исторические записи не выдаются за активные объявления.
- Полный таможенный расчёт TKS.RU отключён. В общей смете пользователь вводит подтверждённые суммы вручную.
- Сохранённые поиски, избранное и история заявок хранятся в браузере и не синхронизируются между устройствами.
- Серверный кабинет, документы и отслеживание этапов сделки пока не являются готовыми функциями.
- Никакие реальные кейсы, отзывы, цены или сроки не публикуются без подтверждения.

## Разработка и проверки
- Backend: FastAPI (api.py), Render.
- Frontend: статический HTML/CSS/JavaScript, Render Static Site.
- CI: Python syntax, unit tests, Node syntax checks.
- Перед выпуском: проверять production endpoint, заявку и оба Render deploy.

## Следующие бесплатные этапы
1. Расширить карточку источника/объявления и фильтры, не подменяя отсутствие лотов демо-данными.
2. Добавить экспорт сметы и локальной истории заявок в CSV/JSON и печать через браузер.
3. Расширить справочник моделей, поколений, двигателей и комплектаций с проверяемыми источниками.
4. Улучшить бесплатные поисковые ссылки по VIN/номеру кузова и фильтры для каждой страны.
5. Проверить доставку заявок в Telegram и fallback на production.
6. Проверить юридические тексты, localStorage и согласия до сбора персональных данных.

Платные источники, синхронизированный кабинет, автоматические уведомления о новых лотах и полный live-каталог остаются вне бесплатного этапа, пока не найдено решение без обязательств и скрытых расходов.
