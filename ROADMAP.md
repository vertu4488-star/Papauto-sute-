# PAPAUTO — дорожная карта бесплатного развития

Актуализация: 31.10.2026. Основной рынок — Япония, Южная Корея и Китай; доставка в Новосибирск и другие города России.

## Неизменные правила
1. Не подключать платные подписки, платные API, кредиты, платные отчёты или автопродление.
2. Не использовать даже старый сохранённый ключ платного поставщика без отдельного согласия.
3. Не выдавать архивные сделки за активные объявления, а поисковые ссылки — за встроенный каталог.
4. Для каждого внешнего результата указывать источник, тип данных, дату и валюту, если они доступны.
5. Не придумывать цену «под ключ», аукционную оценку, историю ДТП, пробег, фото, отзывы, сроки или статус заказа.
6. Если бесплатного источника нет, обеспечить честный ручной сценарий и объяснить ограничение.

## Текущая база
- Адаптивный marketplace-интерфейс, SEO-страницы стран/моделей/регионов.
- Фильтры каталога, локальный поиск по описанию, голосовое распознавание браузера при поддержке.
- Избранное, сравнение до трёх машин, до десяти сохранённых поисков в localStorage.
- Открытые источники JP/KR/CN; прямые каталоги активных объявлений без бесплатного API открываются вручную.
- USS monthly aggregate и публичная месячная статистика Кореи — если источники доступны.
- Ручной калькулятор по введённым пользователем расходам, официальный курс ЦБ РФ.
- Схематический план маршрута и публичные ориентиры логистики с предупреждением о необходимости подтверждения.
- Telegram-передача заявок при наличии серверных Telegram credentials.
- Платные AI/auction API отключены; TKS endpoint закрыт даже при наличии старого ключа.

## Сравнение с Tokidoki, АвтоДилер Тарасов и Automack
| Функция | Конкурентный образец | Бесплатное решение PAPAUTO | Ограничение |
|---|---|---|---|
| Каталог по трём странам | Tamx / Automack | Единый интерфейс фильтров + прямые ссылки на открытые каталоги | Нет бесплатного лицензированного потока лотов всех стран |
| Карточка лота | Tokidoki / Automack | Унифицированная карточка только при наличии проверенных данных; ссылка на первоисточник | Нельзя создавать карточку без конкретной записи |
| VIN/номер кузова | Tokidoki | Поисковые ссылки по номеру кузова и VIN | Бесплатный поиск не гарантирует полный отчёт |
| Статистика закрытых торгов | Tokidoki / Automack | USS monthly aggregate + ссылки на публичные архивы | Нет полной модельной статистики без разрешённого архива |
| Цена «под ключ» | Все три | Расширенная ручная смета, курс ЦБ, явные неизвестные расходы | Платный TKS отключён; ставки и сборы требуют проверки |
| Быстрые подборки | Tamx / Automack | Кнопки бюджета/страны, сохранённые фильтры | Результат зависит от источника |
| Сравнение машин | Tamx | Сравнение до трёх карточек в браузере | Только доступные поля |
| Голосовой поиск | Automack | Browser SpeechRecognition + локальный парсер | Поддержка зависит от браузера |
| Уведомления о лотах | Tamx / Automack | Сохранённый поиск и ручной повторный запуск | Фоновая отправка требует worker и live-источника |
| Личный кабинет | Tamx / Automack | Локальная история заявок и сохранённые данные браузера | Нет синхронизации, документов и статусов |
| Кейсы и отзывы | Tokidoki / Tamx | Только подтверждённые поставки и отзывы с разрешением | Не заполнять выдуманным контентом |
| Контент и справочник | Все три | Страницы моделей, инструкции, чек-листы | Справочные данные должны иметь источник и дату |

## Приоритеты
### P0 — расходы и надёжность
- Закрыть все endpoint платных API, включая TKS, даже если старый ключ остался в Render.
- Убрать из интерфейса кнопки, вызывающие отключённые AI/TKS endpoint.
- Заявка: Telegram-first, без обязательной платной базы; fallback — копирование и отправка вручную.
- Проверить форму, мобильные действия, CORS и обработку ошибок.

### P1 — бесплатный функциональный паритет
- Выполнено в текущем изменении: расширена ручная смета (комиссия, доставка по стране покупки, экспорт/порт, страхование/хранение, международная логистика, таможня, оформление, доставка по РФ, услуги и прочее).
- Выполнено: ручное сравнение суммы заполненных статей с ценой российского аналога, которую вводит пользователь; неполные статьи явно учитываются в предупреждении.
- Выполнено: экспорт сметы в CSV и печать/PDF средствами браузера.
- Выполнено: экспорт локальной истории заявок в JSON и её очистка пользователем.
- Карточка источника: тип данных, дата, валюта, первоисточник, ограничения.
- Улучшить поиск по кузову/VIN через открытые поисковые ссылки.
- Расширить справочник моделей, поколений, двигателей и типичных особенностей.

### P2 — бесплатная эксплуатация
- Локальная история заявок с экспортом JSON; смета экспортируется в CSV и печатается в PDF средствами браузера.
- Экспорт сохранённых поисков и сравнения в JSON/CSV.
- Browser notifications только в пределах возможностей браузера и с согласия пользователя; не обещать фоновые уведомления.
- Оптимизация мобильной скорости, SEO и доступности.

## Вне бесплатного этапа
- Полный live-каталог с частыми обновлениями и фото по трём странам.
- Полный архив закрытых аукционных продаж с листами.
- Полный официальный автоматический расчёт таможни и утильсбора через коммерческий API.
- Синхронизированный аккаунт, CRM, загрузка документов и отслеживание сделки.
- Фоновые уведомления, требующие постоянно работающего worker/планировщика.
Эти функции нельзя обещать без бесплатного источника/инфраструктуры с гарантированными условиями. Любое платное предложение сначала выносится на отдельное согласование.
